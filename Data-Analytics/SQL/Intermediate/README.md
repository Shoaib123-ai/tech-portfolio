
# Intermediate SQL Projects

This folder contains SQL exercises and projects I've completed as I continue developing my data analysis skills.

My focus at this level is on writing more complex queries, working with multiple tables, analyzing data, and applying SQL concepts to practical scenarios.

## Projects

### 1. Employee Compensation Audit

Used SQL to join employee records and identify employees in managerial and director positions based on age, salary, and occupation. Practiced filtering data with multiple conditions and organizing results.

### 2. Employee Compensation Analysis

Analyzed employee salaries to identify individuals earning above the average salary for their occupation. Used a correlated subquery, aggregate functions, and table joins to compare employee compensation.

## SQL Skills Practiced

- INNER JOIN and table aliases
- Subqueries and correlated subqueries
- Aggregate functions such as AVG(), COUNT(), and SUM()
- Filtering with WHERE, BETWEEN, IN, and LIKE
- Combining conditions with AND and OR
- Sorting results with ORDER BY
- Limiting results with LIMIT

## Tools Used

- MySQL
- MySQL Workbench
